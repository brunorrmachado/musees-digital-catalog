# Musees Digital Catalog

Catálogo digital de obras de museus utilizando FastAPI, PostgreSQL e a API GraphQL do Paris Musées.

## Tecnologias

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- GraphQL
- GitHub

## Instalação

```bash
git clone https://github.com/SEU_USUARIO/musees-digital-catalog.git

cd musees-digital-catalog/backend

python -m venv .venv
``
